# CIAJ Web Listo

Proyecto limpio para Netlify + GitHub + Decap CMS.

## Configuración en Netlify

Build command:

```bash
npm run build
```

Publish directory:

```bash
dist
```

Base directory:

```bash
vacío
```

Package directory:

```bash
vacío
```

## Rutas

- `/` Página principal CIAJ
- `/blog/` Blog
- `/admin/` Panel de administración

## Importante

Este ZIP no debe subirse dentro de una carpeta adicional. Sube el contenido directamente a la raíz del repositorio.
